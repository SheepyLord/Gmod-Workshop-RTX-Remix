# i18n.lua

The companion's translations ([ADR 0029](../../../../docs/decisions/0029-companion-translations.md)):
the RTX Remix tab (`nativeloader_menu.lua`), the guide (`nativeloader_guide.lua`) and the package
update notice (`nativeloader.lua`) include it.

```lua
local i18n = include("nativeloader/i18n.lua")
local L, N = i18n.L, i18n.N
panel:Help(L("Start here"))                          -- translated now
local PAGES = { { N("Welcome"), ... } }              -- marked; translated where drawn: L(page[1])
```

- `L(text)`: the translation of `text` in the current language, or `text` itself when there is none.
- `N(text)`: `text`, unchanged. It marks text in tables for
  [`tools/companion_i18n.py`](../../../../tools/companion_i18n.py.md) to extract; the code that shows
  it calls `L`, so the language at that moment applies.
- The language: the client setting `nativeloader_language` (saved; empty by default), else Garry's
  Mod's `gmod_language`. Codes: `en`, `zh-CN`, `zh-TW`, `ja`, `ko`, `fr`, `ru` (`i18n.languages` lists them
  with their own names, for the choice in "Start here").
- The translations come from `nativeloader/i18n_data.lua`, which the RTX package's build writes from
  [`companion/i18n`](../../../i18n/README.md). Without that file (the add-on copied from this repository
  by hand) everything shows in English.
- Changing `nativeloader_language` rebuilds the spawn menu (`spawnmenu_reload`, 0.2 s later) so the tab
  shows the new language.
- The main menu's Lua (R24: the notice before the server browser and the load overlay,
  [`menu/`](menu/multiplayer_notice.lua.md)) cannot see this client setting, so a copy of it is kept for the menu in
  `data/nativeloader_companion/language.txt`: written at load and on a change, only when it differs from the file,
  and only a language code (letters, digits and `-`, at most 16) or empty.
- The module is loaded once per client (the global `NATIVELOADER_I18N`). `nativeloader_i18n.lua` in
  `lua/autorun` sends it and the data file to clients.

Its one file write is that copy; no hooks. Tested by
[`tools/tests/test_companion_i18n.py`](../../../../tools/tests/test_companion_i18n.py.md) (under LuaJIT, with the GMod
functions mocked) and compiled by `test_companion.py`.

Bundled interfaces use `A(text, optionalLanguage)` in a separate namespace. `P(text)` returns a stable
engine phrase key; `RegisterPhrase(key, text)` preserves existing tool/undo keys. Registered phrases
refresh when the override changes or the game language changes while following it. Unknown text
falls back to its original value. `PreparePanel(panel)` gives long slider/combo labels a full-width
help line; it changes only that panel's methods. The add-ons' convar values and control arguments stay intact.

Prepared checkbox labels wrap within the control width while preserving their existing value and change handlers. Native bundled tool panels also call this helper explicitly.
