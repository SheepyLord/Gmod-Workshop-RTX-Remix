## Decisions and open integration

Server slots use the same 44/46/48 order because the brief gives no different server priority; empty descriptors have no resources and follow the shared registry. Harness fixtures expose engine contracts, not a prediction/ballistics/reload simulator. Their explicit limits prevent false confidence in later weapon acceptance. The central reservations own M's sizes so future keyboard/tool overlays cannot alias them.

S has no open implementation item. W/K/T gameplay, P/R/M follow-ups, Q's combined acceptance and shared-probe settling update, worn readability and the user's milestone approval remain open. S changes only its assigned files; no work from sibling branches is merged.
