# test_hotloader_scene_visibility.py

Runs [hotloader_scene_visibility_harness.lua](hotloader_scene_visibility_harness.lua.md) under LuaJIT, once per
scenario, without starting Garry's Mod ([ADR 0245](../../docs/decisions/0245-mmd-hair-and-clothing-leave-out-what-nobody-sees.md)).
The harness loads the Model Hotloader's shipped `packages/model-hotloader/mmd_hotloader/lua/mmdhl/secondary_collision.lua`
whole, as the server loads it, and runs its scene capture's `Tick` hook over stub entities. Each test checks which
physics bodies the capture hands the natives as excluded: entities nobody can see are left out, everything that is drawn
stays in.

```powershell
python -I -m unittest discover -s tools/tests -p test_hotloader_scene_visibility.py    # from the repository root
```

| Test | Checks |
|---|---|
| `test_entities_nobody_can_see_are_left_out` | A no-draw prop, a ragdoll with render mode none (all its bodies) and a prop at colour alpha 0 under an alpha render mode are left out; a visible prop, the character itself, alpha 0 under the normal render mode (drawn opaque) and alpha 1 stay in; `mmdhl.sceneDiagnostics.hiddenEntities` counts the three |
| `test_an_entity_drawn_again_collides_again` | A no-draw prop and Enhanced Death Animations' blank-bodygroup animator are left out; the next tick after the prop is drawn again and the animator shows its mesh bodygroup they are in; hidden again, the prop is left out again |
| `test_models_drawing_no_mesh_are_left_out` | The add-on's model (`barney` bodygroup: a blank submodel and a mesh) is left out at body 0 and kept at body 1; with two bodyparts, one selected mesh keeps a model in; every selected submodel blank, no bodypart at all, or a mesh without vertices leaves it out; a missing file, a file that is not a studio model and an unsupported version count as drawn; a model scaled to 0 is left out, one at 5 % is not; each model file is opened once |
| `test_bone_followers_are_as_visible_as_their_model` | A `phys_bone_follower` (no-draw by the engine) of a visible NPC stays in; one of a model drawing no mesh or of a no-draw model is left out; one without an owner stays in |
| `test_characters_follow_what_the_add_on_draws` | Another MMD character stays in whatever its carrier model holds and whatever its render mode; `MMDHLNoDraw`, alpha 0 and no-draw leave it out |
| `test_stand_ins_explicit_exclusions_and_the_world` | A no-draw entity with `MMDHLSceneStandIn` (the VR hands' spheres) stays in; an `MMDHLSceneExcluded` collider is still left out and not counted as hidden; the world stays in even when flagged no-draw |
| `test_invisible_players_and_npcs_are_left_out` | A visible player and NPC are tagged as players and NPCs; an invisible player and an invisible NPC (a bull's-eye) are left out and not tagged; `livingEntities` counts the visible two |
| `test_entities_without_a_model` | An engine entity without a model is left out; a scripted one without a model (it may draw its own mesh, as broken glass shards do) stays in; a brush entity stays in unless it is no-draw |
| `test_a_hidden_ragdoll_wearing_drawn_models_collides` | The sandbox bonemerge look: a transparent ragdoll wearing a drawn model merged onto its bones stays in; a hidden ragdoll whose children are hidden or draw no mesh is left out |

The studio model files are generated by the harness (the header fields the capture reads: the `IDST` id, the version,
the bodypart count and offset, each bodypart's submodels, each submodel's mesh and vertex counts).

LuaJIT is optional: without it (CI) the tests are skipped. Writes nothing. Exit code 0 on success.
