# vr_tools_review_client.lua

Appended inside the base private client fixture for review/API cases. Owns phase setup,
fault/refusal/admin commands and the deliberately eligible near-hand Use test. Review
records actual physical control owners, movement/arc state and wheel notice. Chooses a
refused crowbar entry by the real wheel movement plane. gm_snapangles is temporarily 45,
saved/restored by the base fixture. API case issues separately labelled native drop API
diagnostics. It never implements a production drop/control path. No files/SDK setup; all
activity is inside the lock/transaction-owning production session; errors fail acceptance.
