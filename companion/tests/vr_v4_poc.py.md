# vr_v4_poc.py

Run S's short simulated scaffold/page acceptance through M's vr_ui_poc.py and the production tools/vr_session.py snapshot/PoC-lock/rollback driver. Example: `py -3 companion/tests/vr_v4_poc.py --package out/dist/PACKAGE.gma --evidence out/vr/v4s/sim-1080 --window 1920x1080 --gui-scaler VERIFIED_FOLDER --seconds 15`. Always adds --simulate and --settings-probe. No OpenVR initialization/VR lock, SteamVR change or field write. Same Pillow preflight, verified GUI Scaler staging and protected-file/depot restoration as M's driver. Captures the scrolled Weapons page as an actual overlay (plus eyes/mirror); scaffold-acceptance.json checks module slots, core settings, canvas, scrolled group, GUI Scaler and Exit. Source hash/snapshot retained. All writes inside the evidence folder or transactional PoC fixture. Exit 0 only when driver/rollback/UI/scaffold pass; nonzero otherwise (including preflight 2).

After the second native Stop, the generated probe waits one second of flat rendering before its existing live-selector comparison. Native off acknowledges session teardown; its first callback can still expose the cached last VR frame's selectors. This bounded settling interval keeps the exact comparison and failure behavior, and changes no production driver file. An assertion requires the expected single final-Stop site before transformation. A source/contract change fails before launching the game.

Q4 integration adds retained coverage and the shared one-second flat-render settlement after the second Stop. No field files or SteamVR settings are changed.
