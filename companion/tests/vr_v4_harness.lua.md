# vr_v4_harness.lua

24 independent scenarios for F's extended vr_stubs.lua; arguments are checkout root and case name, selected by vr_v4_test.py. No game, OpenVR, files, networking or firing simulation. Assertions return nonzero; success prints PASS and exits 0.

Contracts checked against Facepunch's wiki (2026-11-11):

| Cases | Contract |
|---|---|
| weapon, clips, ammo_types, next_fire, world_model, hold_type, scripted | [Weapon methods](https://wiki.facepunch.com/gmod/Weapon), [SetClip1](https://wiki.facepunch.com/gmod/Weapon:SetClip1): independent primary/secondary clips, -1 for no ammo, explicit maximum, next-fire time in seconds and world-model metadata. SetClip1 itself does not transfer reserve ammo. |
| inventory, active | [GetWeapons](https://wiki.facepunch.com/gmod/Player:GetWeapons), [GetActiveWeapon](https://wiki.facepunch.com/gmod/Player:GetActiveWeapon): a list of entities and the active entity/NULL. Fixture order has no engine-order guarantee. |
| ammo_count, give_ammo, remove_ammo, set_ammo | [GetAmmoCount](https://wiki.facepunch.com/gmod/Player:GetAmmoCount), [GiveAmmo](https://wiki.facepunch.com/gmod/Player:GiveAmmo), [RemoveAmmo](https://wiki.facepunch.com/gmod/Player:RemoveAmmo), [SetAmmo](https://wiki.facepunch.com/gmod/Player:SetAmmo): ammo ID/name refer to one reserve; GiveAmmo returns the amount added, with configurable fixture caps. |
| give, strip, select | [Give](https://wiki.facepunch.com/gmod/Player:Give), [StripWeapon](https://wiki.facepunch.com/gmod/Player:StripWeapon), [SelectWeapon](https://wiki.facepunch.com/gmod/Player:SelectWeapon): no duplicate entity, NULL for duplicate/unknown, bNoAmmo leaves reserves alone, strip removes instance, selection by class. |
| buttons, wheel, command_select | [CUserCmd](https://wiki.facepunch.com/gmod/CUserCmd), [GetMouseWheel](https://wiki.facepunch.com/gmod/CUserCmd:GetMouseWheel), [SelectWeapon](https://wiki.facepunch.com/gmod/CUserCmd:SelectWeapon): bit flags, whole-number wheel delta, queued weapon entity rather than immediate inventory selection. |
| bullets | [Bullet](https://wiki.facepunch.com/gmod/Structures/Bullet), [EntityFireBullets](https://wiki.facepunch.com/gmod/GM:EntityFireBullets): same mutable data table, Src/Dir independent of preserved damage/count/callback fields. Default Src/Dir/Spread are zero vectors, HullSize 0, AmmoType empty, Inflictor/IgnoreEntity NULL. Caller supplies Attacker/drives the hook; no ballistics simulation. |
| register | [weapons.Register](https://wiki.facepunch.com/gmod/weapons.Register): registered class table remains available independently of an instance; inheritance/metatable merging is outside this stand-in. |
| attachments | [LookupAttachment](https://wiki.facepunch.com/gmod/Entity:LookupAttachment), [GetAttachment](https://wiki.facepunch.com/gmod/Entity:GetAttachment): one-based IDs, 0 missing, -1 invalid model, nil missing data; Pos/Ang are transformed to world coordinates. |
| bones | [LookupBone](https://wiki.facepunch.com/gmod/Entity:LookupBone), [GetBonePosition](https://wiki.facepunch.com/gmod/Entity:GetBonePosition), [GetBoneMatrix](https://wiki.facepunch.com/gmod/Entity:GetBoneMatrix): zero-based IDs, nil missing; SetupBones produces world-space rigid fixture transforms, not parent-relative ones. Matrix provides translation/angles only. |
| model_lifecycle | [ClientsideModel](https://wiki.facepunch.com/gmod/Global.ClientsideModel), [DrawModel](https://wiki.facepunch.com/gmod/Entity:DrawModel), [Remove](https://wiki.facepunch.com/gmod/Entity:Remove): owned validity/draw/no-draw state. No actual renderer. |

S.Model accepts local-space bones/attachments and entity position/angles. S.Weapon adds explicit clip/ammo/metadata values; no implicit firing/reloading. S.Player accepts weapons, active, ammo, ammoTypes (lower-case name to numeric ID), ammoMax and classes (SWEP-like definitions). S.WeaponRegistry installs the minimal weapons.Register/GetStored table. NULL is an invalid table compatible with the existing IsValid stand-in. No prediction, pickup/Deploy/Holster hooks, inheritance or animations are emulated; feature tests must model those explicitly or prove them in the PoC.
