# sh_protocol.lua: Shared wire protocol

Include returns constants, module number ranges, WriteSync(io, sample), ReadSync(io), ValidateSync(sample, state, eyes, reach) and Packet(writer). START=1 carries one float scale (10..100), STOP=2 has no payload, SYNC=3 totals 1467 bits including the type byte. The sync uses uint32 sequence, a validity bit and three float position/angle components for the head; each hand adds validity, position, angles, velocity (game units/s), angular velocity (Source XYZ radians/s), grip/trigger floats, five curls and uint8 buttons (grip=1, trigger=2, stick_click=4, A=8, B=16). No compressed vectors/angles in the sync. Sequence wrap is accepted only forwards; finite values, reach, analogue ranges and button masks are checked. Hands 16..23, move 24..31, ui 32..39, interact 40..63. Module Send writers receive w: use w.WriteVector(v), w.WriteAngle(a), w.WriteFloat(n), w.WriteDouble(n), w.WriteUInt(n,bits), w.WriteInt(n,bits), w.WriteBool(b), w.WriteString(s), w.WriteEntity(ent), with matching net.Read* on receipt. Writers must use this argument, never global net. Packet snapshots data without replacing net; its 4096-byte conservative bound and signature permit deferred changed-only server sends. No hooks, messages or file writes on include.

Inputs are the session/context arguments described above. Outputs are returned Lua tables and active-session state only. Errors propagate to the owning session or harness; there is no process exit code for production Lua.

V4 widens ModuleType to integral 16..127, with weapons 64..79, reload 80..95, tools 96..111 and 112..127 unassigned. All client/server Send/On and server dispatch checks use this predicate. The sync, payload/rate/reach limits do not change.
